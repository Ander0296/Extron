# CHECKLIST — Leer un manual Extron en inglés

Recorré esta lista MIENTRAS trabajás con un manual, de arriba a abajo.
No es para memorizar: es para no perderte 40 páginas buscando un dato
que está siempre en el mismo lugar.

## Antes de leer una sola línea

- [ ] Mirá la portada: nombre EXACTO del modelo y tipo de documento
      (User Guide = manual completo; Setup Guide = solo el arranque
      rápido). No es lo mismo y no traen la misma información.
- [ ] Mirá cuántas páginas tiene y anotalo. Te dice si vas a poder con
      él de una sentada o hay que partirlo en tandas.
- [ ] Andá al índice (Contents) y leé SOLO los títulos de sección.
      Ese minuto te ahorra media hora después.

## Ubicá la sección que te sirve

Todo manual Extron tiene la misma estructura fija. Buscá por lo que
necesitás, no leas de corrido:

- [ ] ¿Qué ES el equipo y qué hace? → **Introduction**
- [ ] ¿Cómo se conecta, qué entra y qué sale? → **Installation**
      (ahí están los dibujos de panel trasero y las tablas de puertos)
- [ ] ¿Cómo se usa y se configura día a día? → **Operation**
      (panel frontal, interfaz web, LEDs)
- [ ] ¿Comandos, tablas de referencia, resolución de problemas?
      → **Reference**
- [ ] ¿Resoluciones, consumo, medidas, distancias máximas?
      → **Specifications**

## Mientras leés

- [ ] Cada vez que aparezca un cartel, ubicá cuál es:
      WARNING = peligro para VOS · ATTENTION/CAUTION = peligro para el
      EQUIPO · NOTE = dato importante sin peligro.
      Por qué importa: un ATTENTION saltado es un equipo roto, y en
      producción eso es una sala caída.
- [ ] Anotá cada término en inglés que no conozcas y buscalo. No sigas
      leyendo "más o menos entendiendo": en un manual, media palabra
      mal entendida cambia el conexionado entero.
- [ ] Cuando veas una figura (Figure N), miralas ANTES de leer el
      párrafo. Un diagrama de conexionado dice en 3 segundos lo que el
      texto dice en dos párrafos.
- [ ] Si el manual nombra otro documento ("see the X Guide"), anotá el
      nombre y seguí. NO te vayas a leerlo ahora.

## Antes de dar el manual por leído

- [ ] ¿Podés dibujar el camino de la señal de este equipo, de punta a
      punta, sin mirar? Si no, volvé a Introduction + Installation.
- [ ] ¿Sabés qué conectores tiene y qué lleva cada uno?
- [ ] ¿Sabés cómo se accede a configurarlo (IP por defecto, interfaz
      web, panel frontal)?

## Trampas conocidas

| Confusión típica | La diferencia real |
| --- | --- |
| User Guide vs Setup Guide | El Setup Guide es un resumen de instalación; le faltan Operation y Reference. |
| WARNING vs ATTENTION | WARNING protege a la persona. ATTENTION protege al equipo. |
| Class A vs Class B (FCC) | Class A = entorno comercial. Class B = doméstico. Estos equipos son Class A. |
| Número de página del PDF vs del manual | El PDF cuenta las portadas; el manual empieza a numerar en la Introduction. La pág. 7 del PDF es la pág. 1 del manual. |
