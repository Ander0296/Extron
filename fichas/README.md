# fichas/ — el inventario Extron de mi empresa

Una ficha por MODELO de equipo Extron que encuentro en la empresa. Las
escribo yo (Claude solo crea el archivo vacío con la plantilla). Esta
carpeta está protegida por el candado: Claude no puede editarla.

Al final del proyecto, esto es el manual interno de los equipos de mi
empresa. No lo tiene nadie más ahí.

## Plantilla de ficha (la misma para todos)

```
# <MODELO EXTRON>

- Qué es y para qué sirve (una línea, con mis palabras)
- Dónde está en la empresa (sala/rack)
- ENTRADAS: qué conectores, qué señal entra por cada uno
- SALIDAS: qué conectores, a qué va conectado cada uno
- Cómo se accede: IP / panel frontal / web / RS-232
- Cómo se configura lo básico (lo que realmente toco)
- Cómo se resetea (y qué se pierde al hacerlo)
- LEDs y qué significa cada estado
- Fallas típicas y qué verifico primero
- Manual: nombre del PDF y páginas clave
```
